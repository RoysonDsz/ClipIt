# 🎬 ClipIt — Ultimate Media Downloader

ClipIt is a full-stack web app that lets you download videos and music from **YouTube**, **Spotify**, and **Instagram** — all in one slick interface.

Built with:
- ⚡ **Frontend**: Vite + React
- 🔥 **Backend**: Flask (Python)
- 🧠 **Media Magic**: `yt-dlp` for downloading almost anything from the internet.

---

## 🌐 Features

- 🎥 Download YouTube videos or audio (MP4/MP3)
- 🎵 Download tracks and playlists from Spotify
- 📸 Grab reels, videos, and posts from Instagram
- 🚀 Super fast UI thanks to Vite + React
- 🧩 API-driven architecture (Flask backend)
- 📁 File download with clean progress feedback (optional)

---

## 📦 Tech Stack

| Layer       | Stack                     |
|-------------|---------------------------|
| Frontend    | React + Vite + Tailwind   |
| Backend     | Flask (Python) + yt-dlp   |
| Downloader  | [`yt-dlp`](https://github.com/yt-dlp/yt-dlp) |
| Styling     | Tailwind CSS              |
| Packaging   | REST API endpoints        |
